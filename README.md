**AI Customer Support Automation — n8n**
AI-powered customer support automation workflow built with n8n, Gemini, WhatsApp, and Google Sheets.

**Overview**
This project automates customer support by receiving customer messages through WhatsApp, analyzing the request using AI, and retrieving relevant information from Google Sheets.
The workflow is designed to reduce manual support work and provide faster, automated responses.

**Workflow**
WhatsApp → n8n → Gemini AI Agent → Google Sheets → Automated Response
Main Components
WhatsApp — Receives customer messages
n8n — Workflow automation and orchestration
Gemini — AI-powered message understanding and response generation
Google Sheets — Stores and retrieves customer/business information
AI Agent — Determines the appropriate response based on available information

**Key Features**
Automated customer support
AI-based customer message analysis
Google Sheets integration
Automated responses
Workflow-based business automation
Reduced manual customer-support effort

**Technologies Used**
n8n
Google Gemini
WhatsApp
Google Sheets

**Setup**
Import the workflow JSON file into n8n.
Connect your Gemini credentials.
Connect your Google Sheets account.
Configure your WhatsApp integration and credentials.
Update the Google Sheet and required fields according to your business use case.
Activate the workflow.

**Project Purpose**
This project demonstrates how AI agents and workflow automation can be combined to build an automated customer-support system for businesses.
